# Surfaces

Every page this site serves. Generated by `build/surfaces.js` from
`build/routes.js` on every run of `node build/prerender.js`, so it cannot drift
from what actually ships. Do not hand-edit it: the next build overwrites you.

Three docs cite this file as authoritative and it did not exist until 26 Jul 2026.
It is not the same file as `SURFACES.md` in `~/Projects/united-starlink-companion`,
which ranks booking sites for the extension.

## Public routes

All 31 of them are in `sitemap.xml`. `url` is the path Cloudflare
serves; `file` is what lands on disk. Those differ in exactly one row.

`tmpl` names a file in `build/templates/` holding that page's unique content. A
dash means the page is assembled entirely in `build/lib/`. Every route is

## Served but not listed

from `sitemap.xml`.

url        file      title

## JSON endpoints

Pages Functions, computed per request. There is no file on disk and nothing for
the sitemap. They are deliberately absent from `ROUTES`: putting them there would
make the build assert files that must never exist. `/api/docs/` is the one `/api`
path that IS a page. It appears in the route list above instead.

```
endpoint             source
/api/airlines/{key}  functions/api/airlines/[key].js
/api/airlines        functions/api/airlines/index.js
/api                 functions/api/index.js
/api/report          functions/api/report.js
/api/score/{flight}  functions/api/score/[flight].js
```

## Files the site cannot work without

The build fails if one of these is missing. Each is here because losing it would
still return HTTP 200. A missing font falls back silently to three different faces
across three platforms. A missing `flightcheck.js` leaves the hero form sitting
there doing nothing. `build/routes.js` carries the reasoning per file.

- `united/data.json`
- `assets/airlines.js`
- `assets/site.css`
- `assets/site.js`
- `assets/flightcheck.js`
- `assets/og.png`
- `assets/selectors.json`
- `assets/shot-united-1280x800.png`
- `assets/shot-navan-1280x800.png`
- `assets/serif-400.woff2`
- `assets/serif-700.woff2`
- `assets/SourceSerif4-OFL.txt`

## Chrome Web Store links

The masthead puts one link on every page, so only the pages carrying more are
listed. The ship policy fixes the pitch inventory at four surfaces: the masthead
sitewide, the homepage banner, the homepage companion half, and United's
`#plugin` block. Alaska's was removed on 25 Jul 2026.

These are link counts. They run higher than four for that reason. Read a change
in one as a prompt to go look. Read the total as nothing at all.

```
url         links
/           8
/united/    3
/api/docs/  3
```
