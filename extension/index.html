02 · How it works

How the extension labels and sorts flights.

01

Reads the flight number

The extension uses flight numbers shown on the page. It doesn’t read your account, email, fare, or browsing history.

02

Checks public history

United and Alaska flights can get per-flight next-gen WiFi history from public trackers.

03

Adds a clear label

Each number says whether it describes that flight or the airline as a whole.

04

Sorts where undo works

Supported United and Alaska pages use automatic sorting. Keep site order puts each row back.

The two scores answer different questions. Next-Gen estimates the chance that a flight uses a Starlink or Amazon Leo aircraft. Streaming score rates the airline’s WiFi across its whole fleet. The labels keep those numbers separate.

04 · What’s new

Changes in the current extension release.

The current version changes flight recommendations, score labels, and sorting on supported pages.

Chrome Web Store version 3.0.2 · released 2026-08-11

New feature

Best WiFi choice

What it does

Shows a recommendation when at least two flights have usable data, the leader is ahead by eight points or more, and the tracker has medium or high confidence. If those checks fail, WiFi Odds says it cannot pick a winner.

New feature

Separate flight and airline labels

What it does

Marks per-flight next-gen odds and airline-wide Streaming score as different numbers, so you can tell whether the estimate describes your flight or the airline.

New feature

Automatic sorting with undo

What it does

On supported United and Alaska result pages, moves flights with better next-gen odds higher. Keep site order puts the rows back where the booking site placed them.

07 · Missing data and errors

Messages for missing data and errors.

No history, a failed lookup, and too little data get different messages. Open the list below for the meaning of each message.

Messages shown on flight rows

Per-flight odds

The tracker has dated history for this United or Alaska flight. WiFi Odds can compare it after the sample and confidence checks pass.

Verified product behavior · source: extension release commit 99f6b0b9 · checked 2026-08-11

Airline-wide score

The booking page does not provide supported flight history. WiFi Odds labels the airline-wide Streaming score so you do not mistake it for this flight’s odds.

Verified product behavior · source: extension release commit 99f6b0b9 · checked 2026-08-11

Part of the fleet has data

The published score covers a named part of the fleet. WiFi Odds shows that limit and leaves the remaining aircraft unknown.

Verified product behavior · source: extension release commit 99f6b0b9 · checked 2026-08-11

No usable history

The tracker did not return enough history. WiFi Odds shows unknown, does not use 0%, and leaves the row out of the ranking.

Verified product behavior · source: extension release commit 99f6b0b9 · checked 2026-08-11

Lookup in progress

WiFi Odds shows a loading message while it waits for the tracker.

Verified product behavior · source: extension release commit 99f6b0b9 · checked 2026-08-11

Lookup unavailable

The tracker request failed. WiFi Odds keeps the booking site’s order and identifies the lookup error.

Verified product behavior · source: extension release commit 99f6b0b9 · checked 2026-08-11

No flight number

The booking page did not provide an operating flight number. WiFi Odds can show an airline-wide score, but it cannot rank the row as a known flight.

Verified product behavior · source: extension release commit 99f6b0b9 · checked 2026-08-11

08 · Install and privacy

Install and site-access requirements.

Site access

United and Navan work as soon as you install the extension. Alaska and Google Flights stay off until you choose to grant access. There’s no email, login, or remote code.

Where the numbers come from

Per-flight history comes from unitedstarlinktracker.com and alaskastarlinktracker.com. Airline-wide scores keep their own source dates, and missing data stays unknown.
