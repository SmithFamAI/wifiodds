02 · How it works

Three steps. No mystery score.

01

Reads what is already there

Flight numbers on the booking page—not your account, email, fare or browsing history.

02

Looks up dated history

United and Alaska flights can receive per-flight next-gen history from public trackers.

03

Labels, then sometimes sorts

Rows get evidence labels. Supported single-airline pages can reorder with a real undo.

Two numbers, two questions. Next-gen odds estimate the chance that a flight draws a Starlink or Amazon Leo aircraft; the admitted per-flight history currently comes from Starlink trackers. ConnectScore is the carrier-level chance of streaming-class WiFi today. The extension labels them separately.

04 · What’s new

Sharper answers, with escape hatches.

Everything below is bound to the owner-verified Chrome Web Store release record.

01

Evidence-gated Best WiFi choice

Recommends a flight only when the odds gap and confidence justify it; otherwise it explains why no winner is named.

Shipped in Chrome Web Store v3.0.0

02

Labelled next-gen and streaming metrics

Labels every row as flight-specific next-gen odds or an airline-level streaming score so two different measurements cannot look interchangeable.

Shipped in Chrome Web Store v3.0.0

03

Automatic single-airline sorting with a real undo

Automatically sorts supported single-airline result pages by next-gen odds and provides a real undo, while preserving host order where automatic sorting is not offered.

Shipped in Chrome Web Store v3.0.0

Behaviour change: a supported single-airline page can now sort automatically. The page always says when it moved rows and offers Keep site order.

07 · Reference

When WiFi Odds stays silent.

The exhaustive state catalogue remains available for support and review without making every visitor read it first.

Seven flight-row states

Per-flight probability

A dated UA or AS flight history is available. It may enter a comparison when the sample and confidence gates also pass.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

Carrier fleet fallback

No supported flight-level history is exposed. The row may show a labelled carrier measure, but it may not masquerade as this flight’s odds.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

Partial fleet coverage

The published fleet measure covers only a named part of the fleet. The coverage boundary stays visible and unknown aircraft remain unknown.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

No usable history

The tracker answered without a usable sample. The extension says unknown, never 0%, and the row cannot rank.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

Lookup in progress

A temporary loading state appears while the request is genuinely pending. It cannot sit beside a terminal claim.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

Lookup unavailable

The request failed. That is not the same as the tracker reporting no history, so the page order stays unchanged.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

No operating flight number

No flight-specific value is invented. A clearly labelled carrier measure may appear, but it cannot rank this row as a known flight.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

Eight decision outcomes

Best WiFi choice

At least two scored flights, a lead of eight points or more, and high or medium tracker confidence clear the recommendation gate.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

Winner with confirmed aircraft

The airline’s exact-date aircraft assignment appears as a separate grounded fact and can override historical route odds.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

No clear winner: close gap

The leading flights sit inside the decision floor, so both values remain visible and nobody is crowned.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

No clear winner: limited history

A numerical lead exists but its evidence is not decision-grade, so the extension refuses to recommend.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

Not enough to compare

Only one supported flight has a usable score. Other flights stay unscored and in the booking site’s order.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

Comparison in progress

The decision panel is waiting on real lookups and exposes no terminal claim.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

Comparison unavailable

A request failed. The panel distinguishes that outage from a real no-history answer and leaves order unchanged.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

No comparison available

The tracker answered with no direct-flight history for the route. Unknown is not converted to zero.

Tier: measured product behaviour · source: extension release commit 63576edd · source date: 2026-08-02

08 · Install, privacy, provenance

Useful without becoming a travel account.

Permissions follow hosts

United and Navan are ready at install. Alaska and Google Flights are optional grants made from a user gesture. No email, login or remote code.

Evidence stays named

Per-flight history credits unitedstarlinktracker.com and alaskastarlinktracker.com. Fleet measures retain their own source dates. Unknown is never zero.
