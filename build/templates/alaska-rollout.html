What Alaska's record supports is a claim about an aircraft type, not about the jet you end up on. The airline publishes the scheduled type for a departure, and nobody publishes which registration flies it, so the strongest thing this page can say is that an E175 is fitted and a mainline 737 probably is not. The United page can name a tail because the tracker there checks tails. This one cannot, and a per-flight number worked up from a type would read exactly like a real one.

Aircraft assignments change until departure, so any of this can flip on the day. ConnectScore is the chance of drawing the good system: the legacy satellite service on the unconverted part of the fleet earns almost nothing. Nobody publishes per-tail install dates for Alaska, so this page carries no rollout curve. A drawn curve with no install dates behind it would be a guess with a y-axis.
§2 · Per flight

Odds while you are booking

There is no route optimizer for Alaska on this site. A per-flight number needs a tail, nobody publishes which registration flies which Alaska departure, and the nearest available signal is the scheduled aircraft type. The browser extension reads that type off the Alaska results page and bands it the way United is banded, which is as close to a per-flight answer as this tier gets. It is described on the homepage; the alaskaair.com permission it needs is optional and stays off until you turn it on.

§3 · Questions

Alaska wifi, answered

Does Alaska have Starlink wifi?

Yes, on 99 of 350 aircraft (28%): the whole E175 regional fleet plus the ex-Hawaiian widebodies, with the mainline 737s only just starting. Counted from the alaskastarlinktracker.com roster, 2026-07-24.

Is Alaska's wifi free?

Where Starlink is installed it is free for everyone onboard, with no loyalty programme, tier or purchase. That is why Alaska's free-for-you factor is the maximum 1.00 in the ConnectScore arithmetic above.

How many Alaska planes have Starlink?

99 of 350, checked tail by tail by alaskastarlinktracker.com (@martinamps) and read on 2026-07-24.

Which Alaska flight should I book for wifi?

A regional flight on an E175 if the schedule offers one, because that sub-fleet is finished. On mainline, check the scheduled aircraft type before you book and again the day before. That is weaker than the United answer and it is weaker for a reason: nobody publishes which tail flies which Alaska departure, so the type is as far as the record goes.
